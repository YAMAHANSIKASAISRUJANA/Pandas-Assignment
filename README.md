# Pandas Assignment

This repository contains my **Pandas Assignment**, covering fundamental and practical concepts of **Pandas, NumPy, data analysis, data cleaning, and edge-case handling** using Python.

The assignment is implemented in a **Jupyter Notebook** with code, outputs, and explanations for different data-analysis and data-cleaning tasks.

## 📌 Topics Covered

* Pandas Series and DataFrames
* NumPy arrays and operations
* Boolean filtering
* Descriptive statistics
* Mean, median, and maximum
* Group-wise analysis using `groupby()`
* Correlation analysis
* CSV file handling
* Data filtering and sorting
* Missing-value handling
* Data type conversion
* NumPy broadcasting
* Date parsing
* Edge-case analysis
* Duplicate detection
* Data cleaning and standardization
* Invalid-value detection

## 📂 Assignment Sections

### Section A – Output Prediction

Covers basic Pandas and NumPy operations, including:

* Series and DataFrame operations
* Boolean filtering
* Statistical calculations
* Group-wise analysis
* Correlation analysis

### Section B – Code Correction

Focuses on identifying and correcting issues in Pandas code, including:

* CSV data handling
* Data filtering and sorting
* Missing-value handling
* Data analysis
* Correlation calculations

### Section C – Edge Cases

Covers unusual and boundary conditions that can occur during data analysis:

* NumPy broadcasting
* CSV parsing
* Quoted text fields
* Missing values
* Mixed date formats
* Extreme values
* Outlier investigation
* Mean and median comparison

### Section D – Data Cleaning

A student assessment dataset is created and cleaned using Pandas.

The cleaning process includes:

* Loading and inspecting CSV data
* Standardizing department names
* Detecting and removing duplicate records
* Converting marks into numeric format
* Investigating missing marks
* Distinguishing absent and missing entries
* Identifying marks outside the valid `0–100` range
* Reporting data-quality issues
